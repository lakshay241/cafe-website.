TUMBLER & DABARA - CAFE WEBSITE PROJECT
=======================================

FOLDERS
-------
website/
  index.html   -> page structure (open this file in a browser)
  style.css    -> design, colours, layout
  script.js    -> menu, order tray, GST total, opening hours, table booking

flowcharts/
  1_site_flow.png     -> overall website flow
  2_order_flow.png    -> menu and order flow
  3_booking_flow.png  -> table booking flow
  flowcharts.pdf      -> all 3 flowcharts in one PDF
  *.mmd               -> flowchart source (Mermaid), editable at mermaid.live

HOW TO RUN
----------
1. Extract the zip.
2. Open the "website" folder.
3. Double-click index.html (keep all 3 files in the same folder).

Technologies: HTML, CSS, JavaScript (no framework, no backend).
